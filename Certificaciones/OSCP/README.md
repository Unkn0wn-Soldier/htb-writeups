# OSCP+ (PEN-200) — Preparación

> Objetivo: 2028. No empezar en serio hasta tener CPTS. Esta nota es el mapa para cuando llegue el momento.

> [!info] Formato de examen
> 24h de práctica + 24h de reporte. 100 pts: 3 máquinas standalone (20 c/u) + set Active Directory (40). El reporte **se entrega o se reprueba**.

## Temario núcleo (PEN-200)

- [ ] Enumeración y recon
- [ ] Ataques a aplicaciones web (SQLi, LFI/RFI, file upload, command injection)
- [ ] Ataques del lado cliente
- [ ] Password attacks y cracking
- [ ] Port redirection & tunneling (pivoting)
- [ ] Privilege escalation Linux
- [ ] Privilege escalation Windows
- [ ] Active Directory (enumeración, lateral, dominio completo)
- [ ] Metasploit (uso limitado permitido — 1 sola vez en el examen)
- [ ] Reporting profesional

## Prep práctica

- [ ] Lista de máquinas de TJ Null (HTB + PG) — el estándar de facto
- [ ] PG Practice (Proving Grounds) suscripción cuando toque
- [ ] Buffer overflow: revisar si sigue en el temario de tu versión
- [ ] Simulacros de 24h con reporte real

## Relación con CPTS

El CPTS cubre ~80% del temario OSCP con más profundidad en AD y web. Terminar CPTS = base sólida para OSCP. Diferencia grande: el OSCP exige **reporte formal bajo presión de tiempo**.
